# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using HTML and CSS to showcase my skills, projects, and contact information.

## 🚀 Features

- Responsive design
- Clean and modern UI
- Smooth navigation
- Hero section
- About section
- Skills section
- Projects section
- Contact section
- Hover effects and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
